Detailed Description

Arguments data structure for mmwlan_relay_enable().

Warning
ALPHA NOTICE: This is an alpha API that is under development; breaking changes may be introduced in future releases.

This structure should be initialized using MMWLAN_RELAY_ARGS_INIT for sensible default values, particularly for forward compatibility with new releases that may add new fields to the struct. For example:

enum mmwlan_status status;
struct mmwlan_relay_args relay_args = MMWLAN_RELAY_ARGS_INIT;
// HERE: initialize arguments
status = mmwlan_relay_enable(&relay_args);

◆ forwarding_table_size

unsigned mmwlan_relay_args::forwarding_table_size

Maximum number of entries in the forward table.

This must be large enough to hold one entry for every node under this one (direct and indirect). If zero, then the default value, MMWLAN_RELAY_DEFAULT_FORWARDING_TABLE_SIZE, will be used.

◆ recovery_timeout_ms

uint32_t mmwlan_relay_args::recovery_timeout_ms

Duration the relay will wait for the relay network to recover, before bringing down the connection and retrying.

On recovery timeout, the AP interface will be brought down until the relay STA interface successfully reconnects.

Timeout is unused when operating as a root device.

Warning
A device with a relay AP interface may never recover if the timeout is set to UINT32_MAX.

◆ relay_ap_args

const struct mmwlan_relay_ap_args* mmwlan_relay_args::relay_ap_args

Pointer to configuration for relay AP interface.

When present, the device will bring up an AP interface when the STA interface successfully connects to a relay network.

Relay AP interface may be added after enabling the relay, see mmwlan_relay_ap_enable.

Note
The relay AP interface may be brought down if the device loses connection to the relay network and is unable to recover. See recovery_timeout_ms for more.

◆ relay_sta_args

const struct mmwlan_sta_args* mmwlan_relay_args::relay_sta_args

Pointer to configuration for relay STA interface.

When present, the device will bring up a STA interface in the same way as calling mmwlan_sta_enable with the addition of S1G relay awareness. When not present, the device will operate as S1G Relay Root AP.

If NULL, relay_ap_args must be NULL, and root_ap_args must be non-NULL.

◆ root_ap_args

const struct mmwlan_ap_args* mmwlan_relay_args::root_ap_args

Pointer to configuration for Root AP interface.

When present, the device will bring up an AP interface in the same way as calling mmwlan_ap_enable with the addition of S1G relay awareness. When not present, the device will operate as S1G Relay STA/relay.

If non-NULL, relay_sta_args and relay_ap_args must be NULL.

◆ sta_status_cb

mmwlan_sta_status_cb_t mmwlan_relay_args::sta_status_cb

Optional callback to be invoked on STA state changes.

May be NULL. When relay_sta_args is NULL, the callback will be ignored.

Note
The STA status callback must not block and MMWLAN API functions may not be invoked from the callback.
