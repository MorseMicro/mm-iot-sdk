WLAN Control API for S1G Relay functionality
Morse Micro Wireless LAN (mmwlan) API

Detailed Description

API for configuration and control of S1G Relay.

Warning
ALPHA NOTICE: This is an alpha API that is under development. It is not intended for production use. It may be removed in a future release and/or breaking changes may be introduced.

◆ mmwlan_relay_state

enum mmwlan_relay_state

Enumeration of S1G Relay states.

Enumerator
MMWLAN_RELAY_STATE_DISABLED 

Relay mode is not enabled.

MMWLAN_RELAY_STATE_STA 

Relay is enabled on a non-root node whose AP interface is not yet up (STA only).

MMWLAN_RELAY_STATE_RELAY 

Relay is enabled on a non-root node whose AP interface is up, relaying for children.

MMWLAN_RELAY_STATE_ROOT 

Relay is enabled on the root node of the relay tree.

Enable S1G Relay mode.

The relay mode must be enabled prior to enabling the STA or AP, to ensure the device connects to the relay network with relay awareness.

Warning
ALPHA NOTICE: This is an alpha API that is under development; breaking changes may be introduced in future releases.
Parameters
argsArguments from application.
Returns

uint8_t mmwlan_relay_get_depth ( void  )

Get the current S1G Relay depth.

The depth is the number of links between this device and the root node.

Warning
ALPHA NOTICE: This is an alpha API that is under development; breaking changes may be introduced in future releases.
Returns
The current relay depth, or MMWLAN_RELAY_DEPTH_UNKNOWN if the depth is unknown because relay is not active or the node has no path to the root.

◆ mmwlan_relay_set_depth_override()

enum mmwlan_status mmwlan_relay_set_depth_override ( uint8_t  depth)

Set the S1G Relay depth override.

A depth of 0 clears any configured override.

Warning
ALPHA NOTICE: This is an alpha API that is under development; breaking changes may be introduced in future releases.
Note
This is a test API and is not intended for use outside of testing.
Only valid while STA and AP are both disabled.
Parameters
depthRelay depth override, max value of MMWLAN_RELAY_MAX_DEPTH.
Returns
MMWLAN_SUCCESS; MMWLAN_UNAVAILABLE if STA/AP active; MMWLAN_INVALID_ARGUMENT if depth is out of range.
