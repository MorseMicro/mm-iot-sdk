◆ mmwlan_relay_enable()

enum mmwlan_status mmwlan_relay_enable ( const struct mmwlan_relay_args *  args)

Enable S1G Relay mode.

Bring the device up as part of an S1G relay network. The device can be one of three roles:

  • Root: Device at the root of the relay network. Responsible for operating the network. Root cannot change role while relay mode is enabled.
  • Relay: Device operates as a STA + AP in the relay network, forwarding traffic to and from the root. To avoid confusion between the relay role and the subsystem, we refer to an S1G Relay "Relay" as a repeater. A Repeater may transition to STA role at any time, by bringing down its relay AP interface. See mmwlan_relay_ap_disable.
  • STA: Device operates as a STA in the relay network. This is equivalent to operating with mmwlan_sta_enable but with additional awareness of the relay topology. Relay STA can be promoted to repeater at any time. See mmwlan_relay_ap_enable.
Note
: Relay mode cannot be enabled if the STA or AP interface is already enabled.
Warning
ALPHA NOTICE: This is an alpha API that is under development; breaking changes may be introduced in future releases.
Parameters
argsArguments from application.
Returns
MMWLAN_SUCCESS on success, MMWLAN_NOT_SUPPORTED if S1G Relay support was not enabled at build time, MMWLAN_INVALID_ARGUMENT if arguments are invalid, or another appropriate error code.
