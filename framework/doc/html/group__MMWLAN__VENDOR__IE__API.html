WLAN Vendor Specific IE add / clear API
Morse Micro Wireless LAN (mmwlan) API

Detailed Description

API for adding and clearing Vendor Specific IEs.

These elements can be added to Beacon, Probe Response and (Re)Association Response frames.

◆ mmwlan_add_vendor_ie()

enum mmwlan_status mmwlan_add_vendor_ie ( const struct mmwlan_vendor_ie *  ie)

Append a Vendor Specific IE to the active list of Vendor Specific IEs.

Note
This will block until the Vendor Specific IE has been added or some error has occurred.
If MMWLAN_NO_MEM is returned while an AP is running, the IE has been stored and will be applied on the next AP (re)start, but the currently running AP could not be updated. The store is not rolled back, so re-adding the same IE would create a duplicate entry.
Parameters
ieDescriptor of the Vendor Specific IE to add. Must not be NULL. The element contents are copied internally, so the caller retains ownership of the struct memory.
Returns
MMWLAN_SUCCESS on success, else an appropriate error code.
